

# Dress for rent 
  

### Introduction

This project is about developing a management system for a dress rental store.
The system is designed specifically to manage the process of renting dresses, tracking orders and returns, handling customer and employee information, managing payments, and overseeing dress cleaning and maintenance.
The system ensures an organized rental process, accurate payment tracking, and efficient customer service.
Key entities in the system include Dress, Order, Customer, Employee, Laundry, and Payment, with all necessary data recorded to support the daily operations of the dress rental business.
